# Chưa kích hoạt

Project scaffold cũ được giữ để không mất nội dung, nhưng đã đưa ra khỏi solution đang triển khai. Chưa có nghiệp vụ worker và không chạy/deploy project này. Khi tới module cần job nền, quyết định dùng BackgroundService trong API hoặc host riêng theo plan; không coi Hello World hiện tại là worker đã hoàn thành.
